 mdrender                                                                                                        
                                                                                                                   
  mdrender — это легковесная утилита на языке Go для красивого отображения Markdown-файлов прямо в терминале.      
  Программа преобразует разметку Markdown в отформатированный текст с использованием ANSI-последовательностей,     
  что                                                                                                              
  позволяет читать документацию, не покидая консоль.                                                               
                                                                                                                   
  ## 🚀 Основное назначение                                                                                        
                                                                                                                   
  Основная цель проекта — предоставить разработчикам простой способ быстрого просмотра  .md  файлов с сохранением  
  визуальной структуры (заголовки, списки, жирный текст, блоки кода) в командной строке.                           
                                                                                                                   
  ## ✨ Возможности                                                                                                
                                                                                                                   
  • Рендеринг в терминал: Качественное преобразование Markdown в визуально приятный вывод с помощью библиотеки     
  glamour .                                                                                                        
  • Поддержка стандартной разметки: Корректная обработка большинства элементов Markdown.                           
  • Простой интерфейс: Работа через аргументы командной строки.                                                    
                                                                                                                   
  ## 🛠 Установка и использование                                                                                   

                                                                                                                 
  ### Требования                                                                                                   
                                                                                                                   
  • Go 1.18 или выше                                                                                               
                                                                                                                   
  ### Запуск                                                                                                       
                                                                                                                   
  Клонируйте репозиторий и запустите программу, указав путь к вашему Markdown-файлу:                               
                                                                                                                   
    go run main.go README.md                                                                                       
                                                                                                                   
  ### Доступные флаги                                                                                              
                                                                                                                   
  •  --help  — показать справку по использованию.                                                                  
  •  --version  — вывести текущую версию приложения.                                                               
                                                                                                                   
    go run main.go --version
